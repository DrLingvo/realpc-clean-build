# Эталонные профили

Готовые согласованные профили, сгенерированные `tools/gen-profile.py` с фиксированным seed.
Каждый каталог содержит:
- `profile.args` — строка `args:` для конфига ВМ (работает с любой сборкой);
- `profile.env` — правки для `config.env` (нужны, только если тип/форм-фактор памяти профиля
  отличается от вашей текущей сборки — тогда пересоберите QEMU).

Свой случайный профиль: `python3 tools/gen-profile.py --platform <...> --out mydir`
(`--list` — список платформ, `--seed N` — воспроизводимость, `--kind gaming|neutral`).

Не используйте один и тот же профиль на многих ВМ — смысл в уникальности.
